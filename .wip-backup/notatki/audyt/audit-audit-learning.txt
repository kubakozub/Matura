SUMMARY: Srs.kt is the only promotion rule: Leitner boxes 0..3, intervals 1/3/7 days, day = floorDiv(ms, 86 400 000) (UTC), progress key = entryId + U+001F + direction (RANDOM rejected). Srs.apply: PRZERWANA is a no-op; BLEDNA sets box to min(box, 1) (box 0 stays 0), due today, assistedDay, mistakes+1; POKAZANA sets assistedDay only; POPRAWNA promotes only if due, not assisted today and not promoted today; ROZPOZNANIE (ABCD, true/false) is capped at box 1. All four modes send one Attempt per answer through App.kt zapiszProbe (192-201) to Repository.recordAttempt, which applies Srs.applyTo and, for rounds started from the daily session, Sesja.zaliczOdpowiedz in the same save; refresh() is skipped until finish/exit. Sesja.kt plans the day (at most 12 words: due words with history first, then at most 5 never-tried) as steps POWTORKA, GRA, PODSUMOWANIE; StanSesji (step index, done lists, startMs) is persisted in SaveData.sesja. App.kt re-plans from data.progress on every entry to Screen.DzisiejszaSesja, resumes with Sesja.wznow, and starts both step kinds as a CLASSIC round on a MIX_ID set (9 lives when calm); the round ends in MENU. Trudne.kt derives the hard-words list per direction from WordProgress (overdue with box >= 1, mistakes, hints); TrudneSlowaScreen practises through a CLASSIC mix round. EntryId.kt gives catalog entries 'w'+sha256 ids (frozen sense, aliases) and user entries random 'u' ids, reconciled on edit. Podsumowanie.kt and ui/PodsumowanieRundy.kt (round summary, set progress, correction proposal) are complete and unit-tested but have no call site; only Podsumowanie.forma is used (Strings.kt). Tests pin the Srs rules, plan selection on closed vocabularies, hard-word reasons, summary arithmetic and the task kind per mode. Nothing pins the App.kt wiring.

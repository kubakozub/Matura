SUMMARY: Navigation is a hand-rolled stack in MaturaApp (app/src/main/java/com/matura/app/ui/App.kt): sealed interface Screen (Start, Menu, SetPick, ModePick, Play, Sets, Editor, Options, Achievements, Scores, Privacy, TrudneSlowa, DzisiejszaSesja, plus debug-only VoiceTest/RawMic), `stack` held in plain `remember` (no saved state), push/pop/replaceTop and one root BackHandler. `data: SaveData` is re-read from Repository only in `refresh()`. The Play branch builds two write lambdas: `zapiszProbe` -> repo.recordAttempt (every answer, all four modes, no refresh) and `finish` -> repo.recordGame (game over only; the single place where Profile counters and scores change). Three App-level vars steer rounds: `mixSet` (unsaved WordSet behind MIX_ID), `rundaSpokojna` (lives 9) and `planSesji`; `dzisiaj` is computed once. ui/Screens.kt holds StartScreen, MenuScreen (logo, name, eight MenuButtons), SetPickScreen (topic folders from WordSet.category), ModePickScreen, SetsScreen (flat list), SetEditorScreen, OptionsScreen (lives stepper 1..9, chips, direction rows; diagnostics only in debug), AchievementsScreen (eight badges derived by Achievement.unlockedBy(Profile)), ScoresScreen (top 25 of data.scores with a mode filter) and PrivacyScreen. Common.kt provides ScreenScaffold, MenuButton, PrimaryButton, GhostButton, InfoCard, StatRow, Pill; PixelFont.kt draws labels from a 93-glyph sheet (PixelText adds a contentDescription). Strings.kt is the PL/EN table Str (private `pick`) and the in-app privacy policy; the session screen has its own SesjaStr. Checked and found consistent: badge thresholds against the 3/6/9 -> x2/x3/x5 curve used by all four modes (COMBO_X3 at 6, COMBO_X5 at 9); all 229 PL/EN pairs (no swapped sides, placeholders match); every built-in word, title and UI label fits the bitmap font; no in-app text states a 1..5 lives range (only README and the design PDF do); the only language probe by string comparison is Screens.kt:773.
